# Viral Cloud reports

Viral Cloud is the report generated by the independent [FluPop pipeline](https://github.com/crackberryq/Viromics_FluPop).

In Virologix, open Pipelines, install FluPop, and run the synthetic demo or submit supplied records. Virologix displays the completed report and downloads its files. It does not generate the report itself.

Existing reports from the bundled v0.1.0a7 preview remain accessible under Runs. They are legacy outputs; updating the manager does not rerun or modify them.

See [FluPop's input documentation](https://github.com/crackberryq/Viromics_FluPop/blob/main/docs/records.md) for record semantics and interpretation limits.
